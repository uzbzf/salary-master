# 💰 Salary Tracker

Полнофункциональное веб-приложение для учёта личных финансов с отслеживанием доходов, расходов, аналитикой и системой аутентификации пользователей.

## 🚀 Технологии

### Frontend
- **React 18** — библиотека для построения пользовательских интерфейсов
- **Vite** — быстрый сборщик и dev-сервер
- **React Router** — маршрутизация с защитой роутов
- **Recharts** — графики и диаграммы
- **CSS Modules** — стилизация компонентов
- **Context API** — управление состоянием аутентификации

### Backend
- **Node.js 20+** — среда выполнения JavaScript
- **Express.js** — веб-фреймворк
- **SQLite** — встроенная база данных
- **sqlite3** — драйвер для работы с SQLite
- **bcrypt** — хеширование паролей
- **jsonwebtoken (JWT)** — аутентификация по токенам
- **CORS** — middleware для кросс-доменных запросов

## ✨ Функциональность

### 🔐 Аутентификация
- Регистрация нового пользователя (email, имя, пароль)
- Вход в систему по email и паролю
- JWT-токены со сроком действия 7 дней
- Автоматическое восстановление сессии при перезагрузке страницы
- Автоматический выход при истечении токена (401)
- Защита всех приватных роутов от неавторизованных пользователей
- Хеширование паролей с помощью bcrypt (10 раундов)
- Изоляция данных: каждый пользователь видит только свои операции

### 🏠 Главная страница (Dashboard)
- Отображение общего баланса, суммы доходов и расходов
- Список последних 5 операций
- Быстрое добавление новых операций через модальное окно
- Удаление операций с красивым подтверждением

### 📜 История операций (History)
- Полный список всех операций (доходы и расходы)
- Фильтрация по типу операции (доходы/расходы)
- Фильтрация по категории
- Фильтрация по периоду (сегодня, неделя, месяц, год)
- Редактирование и удаление операций
- Русские названия категорий с эмодзи-иконками

### 📊 Аналитика (Analytics)
- Круговая диаграмма расходов по категориям
- Столбчатый график доходов и расходов по месяцам
- Переключение периодов для круговой диаграммы
- Интерактивные графики с подсказками

### 📥 Экспорт данных
- Выгрузка операций текущего пользователя в CSV-файл
- Совместимость с Excel (BOM для кириллицы)
- Кнопка экспорта в шапке приложения
- Безопасная передача JWT-токена в заголовке Authorization
